# ARC-M0-001 · Codex 实施任务单：数据与评测器

**状态**：READY FOR IMPLEMENTATION · 未执行；**依赖**：RFC-001 v0.1、ARC-EVAL-001 v0.1、ARC-EXP-001 v0.1（PROPOSED）

## 目标
在不运行模型、不要求 GPU 的前提下，建立 SciFact/WANDS 的统一 Adapter、不可更改的 Query 划分、可重现的数据和相关性标签验证，以及经小型人工用例验证的 IR 指标计算和标准 Runfile 接口。不要实现 BM25、Dense、Hybrid 或 Rerank（这些属于 M1/M2）。

## 输入与权威来源
- SciFact 官方 BEIR 预处理数据（corpus, queries, qrels/test, qrels/train）。
- WANDS 官方 Wayfair 仓库 `dataset/{product,query,label}.csv`，原始文件为 TSV 分隔时必须按实际原格式正确加载，不能从后缀推断分隔符。
- 阅读 `ARC-EXP-001` 的所有数据规模、唯一键、相关性标签、WANDS 80/400 SHA256 确定性划分规则。仅以官方原文件为数据权威，优先获取具体 commit/revision 和 SHA256。

## 必须实现
1. 两个 Domain Adapter：统一导出 `entities`、`units`、`queries`、`qrels`；V0 Entity = Unit 1:1，SciFact 为文档，WANDS 为商品；ID 和来源可逆映射，任何无效引用报错。
2. 数据稽核：原始规模、字段缺失、编码、标签分布、重复和冲突 `(query_id, product_id)`、孤立 ID、各 Query 正例数；允许自动归并完全一致的重复标签，冲突须失败并报告，不允许 last-write-wins。
3. WANDS 开发/测试拆分：以 `SHA256('ARC-WANDS-v0.1|'+query_id)` 升序取前 80 做 dev，剩余 400 test；写出 ID manifest 和哈希。按 query_id 分组，绝不能随机拆分逐行标签。
4. 评测器：NDCG@10（使用 `2^rel - 1` 和 `log2(rank+1)`）、SciFact Recall@100、WANDS Observed-Recall@100、WANDS Judged@10；全部 Query 等权 macro；未标注 item 仅计分上 gain=0，不作为真实判负。对空 Runfile 返回零指标；所有异常报告明确。
5. TREC Runfile 导入、导出与校验：`query_id Q0 entity_id rank score run_tag` 六列；每个 Query 结果唯一、rank 连续、合法 Entity ID；score 可人工合成且不跨策略比较；稳定 tie-break。
6. 两个人工构造的最小测试用例：包含多级 gain、排名错位、未标注商品、负标签、空排名、重复 ID、全正例被召回、测试 ID 泄漏检出；在注释中手算期望结果。
7. 产出 `dataset_manifest.json`、`dev_query_ids.json`、`test_query_ids.json`、`audit_report.json`、`m0_smoke_metrics.json` 及 README 复现步骤。不要下载/提交大型原始数据进 Git；下载失败明确失败而非生成假数据。

## 硬性不变量
- `|SciFact corpus| == 5183`，`|SciFact test queries| == 300`（以 BEIR 官方预处理版本为准，不符时阻止正式报告）。
- `|WANDS products| == 42994`，`|WANDS queries| == 480`，`|WANDS labels original| == 233448`（清洗后的 unique pairs 数可不同，须报告）。
- `dev ∩ test == ∅`；`|dev| = 80`，`|test| = 400`；所有标签的 Query 必须在完整 480 Query 中。
- WANDS 没有全库穷举标签；不得将未标注商品写成真实 `Irrelevant`。
- 禁止把 WANDS 的 `query_class`、所有 Qrels 标签注入检索输入；仅供评测或可标注的后验分析。
- 同一 Runfile 与 Qrels 多次运行得出相同指标；不同测试/开发 Qrels 不可交叉使用。

## 交付完成的判定
- 单命令执行全部小型单元测试且通过。
- 单命令对原始官方数据运行 Adapter 和审计，打印两套数据规模并保存版本指纹、拆分清单和报告。
- 能对两套数据的**人工合成** Runfile 给出合法指标，且结果可人工复核。
- 不能通过上述任一条件则 M0 不算完成；不得报告模型分数或默认进入 M1。

## 不属于 M0
模型下载、模型训练、BM25 质量分数、GPU 速度测试、FastAPI、Docker、多模态、Agentic Search、外部排行榜对比。
