# ADR-003 · WANDS 冲突标注治理

状态：已批准，2026-11-05。适用于 ARC-WANDS-400 的主评测和开发拆分。本 ADR 只修订 ARC-EXP-001 执行审定附录的冲突标注治理规则。

## 输入与决策

Wayfair WANDS 固定提交 `3b74dcf4ba29ab8ff3e6a50b5b09fc627cb882b5` 的原始三份 TSV 均通过 Git blob 校验。标签文件 SHA-256 为 `c11fe81ad62f17f56f316b0ec9630ebe8fbe1393578cb0ca4f05c17253a180ef`。商品与查询文件、拆分和主 Qrels 的指纹见 [M0 验收记录](../../artifacts/acceptance/m0/checks.json)。

233,448 行原始标注中有 1,561 行可按同对同等级去重，14 个查询—商品对有两个不同等级。五对为 Irrelevant/Partial，九对为 Partial/Exact。逐对 ID、观察到的等级和拆分见 [DISPUTED 清单](../../src/arc/evaluation/wands_disputed.json)，其 SHA-256 为 `6e5668b241f565da85edf6c9e2894c89d9fca04cea0cf95140d502becfcc9b7d`。清单只用于离线评测。

- 仅将清单中与实测 ID 和等级完全匹配的 14 对标记为 DISPUTED，并从主 Qrels 排除。遇到未批准的新冲突、等级变化、清单失配或孤立 ID，准入失败。
- 保留所有原始记录、480 条查询、42,994 个商品、80/400 拆分和检索预算。保留其余正常标注，同对同等级仅保留一次。主 Qrels 有 231,859 对，其中 dev 30,759 对，test 201,100 对。
- DISPUTED 在主评测中是未判定。其返回项仅按指标公式计零 gain，不计入 Judged@10，也不解释为真实负例。排除可能改变理想 DCG、已观测正例分母和 judged coverage。
- 主 Qrels 中有一条 dev 查询（ID 366）无正例，test 无此类查询。保留该查询并按既有规则计 NDCG 和 Recall 为零。它不属于受争议的 14 条查询。

## 敏感性分析

在 M1/M2 固定正式 Runfile 后，用原始观察到的低、高等级分别重算 WANDS NDCG@10，主结果继续采用排除规则。两套情景对同一查询和商品使用相同等级，比较主结果与两套情景的 E1/E2、E3/E4 及其余正式配对差异。每条受影响查询只有一个争议对，因此还可对每条查询的两个端点取配对差值最小值和最大值，再作宏平均，得到所有混合等级选择下的配对差值区间。报告是否可能改变模型比较的方向以及受影响查询的差异。敏感性情景仅用于诊断，禁止用于 test 调参。
